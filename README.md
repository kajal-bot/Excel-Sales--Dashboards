# Excel Sales Dashboard Project

## Project Overview
This project analyzes sales data using Microsoft Excel and demonstrates  performance tracking through dashboard visualization.

## Objectives
- Analyze total revenue and sales trends
- Identify Top 5 performing products
- Evaluate category and regional sales contribution
- Present insights using interactive dashboard

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Data Cleaning Techniques
